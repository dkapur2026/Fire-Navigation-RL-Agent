# Adaptive-agent study: ranch blueprint, 100 seeds per cell

Generated by `python scripts/adaptive_study.py --seeds 100 --lag-seeds 60` (163 s wall on 8 cores). Score = fraction of dependents rescued, 0 if the rescuer dies.
Same seeds and fires for every agent; brackets are 95% paired-bootstrap intervals over seeds.
`gap closed` = (agent - baseline) / (oracle - baseline), `n/a` when the oracle gap is under 0.05.
