Generated by `python scripts/adaptive_study.py --seeds 100 --lag-seeds 60` (624 s wall on 8 cores). Score = fraction of dependents rescued, 0 if the rescuer dies.

`gap closed` = (agent - baseline) / (oracle - baseline), `n/a` when the oracle gap is under 0.05.

moved closer to the truth than the textbook value. Delay: ticks from the change to that edit (median, quartiles),
over recovered episodes. Wrong edits: episodes with an edit to a rule that did not change.
